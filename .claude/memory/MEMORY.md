# Memoria del equipo para este repo

> Regla: acá va **solo lo que no se deriva del código ni del git**. No guardes "usamos Sidekiq" (está en el Gemfile) ni "la rama default es develop" (está en CLAUDE.md). Sí guardá hechos con esta forma (los corchetes son placeholders, no hechos de este repo): «dejamos de cachear <algo> después del incidente <ticket>», «no mockear <componente> porque <razón>», «el usuario pidió no <acción> en <archivo> porque <razón>».
>
> Un archivo por hecho, `<tipo>-<slug>.md`, tipo ∈ `decision`, `limitacion`, `incidente`, `feedback`, `referencia`. Frontmatter: `name`, `description`, `tipo`, `revisado` (fecha ISO). Cuerpo: qué pasó o qué se decidió, **Por qué**, **Cómo aplicarlo**. Revisá las entradas con más de 6 meses sin `revisado:` y actualizá la fecha o borralas.
>
> Este índice lleva una línea por entrada, nunca el contenido.
